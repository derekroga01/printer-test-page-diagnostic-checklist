# Printer Test Page Diagnostic Checklist

Hi, I am Derek Roga, a web developer in Vilnius and founder of Essence Technologies. During support work, the same call kept coming in: the printer is printing wrong. It was rarely a hardware fault. Usually it was a low cartridge, a clogged nozzle, a wrong setting, or badly loaded paper. A printed test sheet turns a vague complaint into something you can see and compare. Print the sheet that matches your symptom, look at it in good light, and work through the checks below before you buy parts or call for help.

## How to use this checklist

Use one sheet at a time. Start with the symptom that bothers you most, print that sheet, and tick off each check. If a check fails, do the fix beside it, then print the same sheet again and compare the two prints. Keep the first bad print as your before picture. If two symptoms appear together, start with the Quick sheet, then move to the clearer symptom.

## 1. Faded or streaky prints

Print the Black and White sheet and look at the grey steps, from light grey to solid black. Each step should be smooth and even, with no pale patches or white streaks. If the pale steps fade first, the black cartridge is probably low or the nozzles are partly blocked. Run one cleaning cycle, then print again. If the same steps stay pale after cleaning, check the level and replace the cartridge. If only one step looks grainy, try normal quality on plain, clean paper, because a draft setting uses too little ink. This points to the cartridge or the print head, not to the paper feed.

## 2. One colour missing, or wrong colours

Print the CMYK sheet and check each channel separately: cyan, magenta, yellow, and black. Each block should be solid, with no missing stripes and no colour that looks like another colour. If one channel is missing, that cartridge is empty, not seated correctly, or blocked. Reseat it, run a cleaning cycle, and print again. If one colour prints as another colour, check the cartridge order and levels. If all four look washed out, check the paper type setting, because a glossy setting on plain paper can leave too little ink on the page. This points to a cartridge, not to the printer itself.

## 3. Banding or lines across the page

Print the Color sheet and look for horizontal bands, lines, or stripes across solid areas of colour. Even bands at regular intervals usually point to the print head or the paper feed. Run a nozzle check, then a cleaning cycle, and print again. If the bands stay in exactly the same place, run the print head alignment routine. If the bands move after cleaning, the nozzles were partly blocked, so clean once more. Bands on one colour point to that cartridge. Bands on every colour point to the rollers or the print head.

## 4. Crooked, doubled, or blurry text

Print the Alignment sheet and look at the lines, crosses, and text. Straight lines should be straight, and text should be sharp, with no doubling, shadows, or blurred edges. If vertical lines lean or text looks doubled, run the alignment routine, then print again. If text is blurry in one direction only, the paper may be slipping, so reload it neatly, push the guides snug against the stack, and print one sheet at a time. Crooked output that changes from page to page is usually a feed problem. Crooked output that is identical every time is usually an alignment setting.

## 5. A general first check

Print the Quick sheet first whenever you are not sure where to start, or when a printer has been idle for a while. It shows the most common faults on one page: faded text, a missing colour, banding, and alignment. If it looks clean, the printer, cartridges, and feed are probably in good shape, and the problem is more likely in the document or the settings. If it shows a fault, note which area failed, then print the matching sheet above. Use it again after a cartridge change, a move, or a long idle period.

## Quick checklist

- [ ] Quick sheet printed, general check passed
- [ ] Black and White sheet, grey steps even
- [ ] CMYK sheet, all four channels solid
- [ ] Color sheet, no banding or lines
- [ ] Alignment sheet, lines straight and text sharp

## Printing correctly

Print each sheet at 100 percent, or Actual Size, with no scaling, fit to page, or shrink to fit. Scaling changes the size of the test patterns and can hide an alignment fault. Choose the paper size that matches the paper in the tray, A4 or US Letter, and print one sided, on plain paper unless the sheet says otherwise. Check that the paper is dry, flat, and loaded as your printer manual describes. If a sheet still looks wrong, print it from a different app, because a viewer or browser setting can add its own scaling.
